# Implementation Plan — UI Redesign (Perplexity + Claude, Light Mode)

Visual/styling overhaul of the Next.js 16 traffic-camera dashboard. Move away from the
dark `slate-950` surveillance admin look toward a calm, warm, light design borrowing the
Perplexity + Claude (Anthropic) design language. **Styling/markup only** — no changes to
props, state, polling, data flow, or exported APIs. Fonts may be added only via
`next/font/google`.

## Context discovered during exploration

- **Stack:** Next.js 16.4.0 App Router, React 19.3, Tailwind CSS v4 (`@import "tailwindcss"`,
  no `tailwind.config.*`), TypeScript. Package manager **bun** (reachable in this env at
  `/Users/zeph/.local/share/mise/installs/bun/latest/bin/bun`; `bun` may not be on a bare
  shell PATH — use the mise path or `mise exec`).
- **CRITICAL FONT FINDING:** `app/globals.css` has **no `@theme` block**. The `--font-lexend-sans`
  / `--font-geist-mono` variables declared in `layout.tsx` are therefore **not wired into
  Tailwind** — the `font-sans` class on `page.tsx` currently resolves to Tailwind's default
  apple-system stack, and `body` hardcodes its own apple-system stack. To make fonts (incl. the
  new serif) actually apply, add a Tailwind v4 `@theme` block mapping `--font-sans`,
  `--font-mono`, `--font-serif` to the next/font CSS variables.
- **Design tokens** live as plain CSS custom properties in `:root` in `globals.css` plus the
  hardcoded `body` rule. Components mostly use **literal Tailwind color classes**
  (`bg-slate-900`, `text-blue-400`, etc.), not the `:root` tokens — so retheming is primarily
  find-and-replace of literal utility classes per file, with the `:root`/`@theme` block as the
  source of truth for shared values and for anything that reads `var(--...)`.
- **Map:** `camera-map.tsx` builds Leaflet `divIcon` markers with **inline-styled HTML strings**
  (hex colors hardcoded in template literals) and binds tooltips with inline HTML. The tile
  layer uses `className: "osm-dark-tiles"`, and `globals.css` inverts tiles via the
  `.osm-dark-tiles` filter and darkens `.leaflet-container` / `.leaflet-popup-*`.
- **No-scroll shell:** `body` is `overflow:hidden`; `page.tsx` is `h-screen w-screen
  overflow-hidden`. Composition = left sidebar (20%) / full map / top-right HUD / bottom events
  pane. Preserve this exactly.
- Lint is green on the base tree (`bun run lint` exits 0).
- `AGENTS.md` block under `website/` is auto-generated by `next dev`; if it appears in the diff,
  commit it, don't fight it.

## Token / palette map (source of truth)

Define these in `globals.css` `:root` and reference the font ones from a `@theme` block.
Use them as the vocabulary; most component edits are literal Tailwind class swaps that match
these values.

Semantic colors are **desaturated** so they sit calmly on cream. Keep traffic-light semantics,
but drop neon glow (`shadow-<color>`) in favor of soft natural shadows
(`shadow-[0_1px_2px_rgba(0,0,0,0.06)]`, `shadow-sm`). Drop `backdrop-blur` on opaque light
panels. Cut most `uppercase tracking-*` micro-labels to sentence case. Use `<Badge>` sparingly.

## Typography decision

- Keep **Lexend** (already imported) as the sans body/UI font — clean humanist sans that fits
  the Claude/Perplexity feel.
- Keep **Geist Mono** for IDs/coordinates/telemetry numbers.
- Add **one warm serif via `next/font/google` for brand/title + large headings only**:
  **Fraunces** (`variable: "--font-fraunces"`), wired exactly like the existing fonts and
  exposed as a CSS variable on `<html>`. Apply it only to the sidebar brand title and any large
  display heading via a `font-serif` utility (mapped in `@theme`).
- Wire all three into Tailwind by adding a `@theme` block to `globals.css`:
  `--font-sans: var(--font-lexend-sans)`, `--font-mono: var(--font-geist-mono)`,
  `--font-serif: var(--font-fraunces)`. This is what makes `font-sans`/`font-mono`/`font-serif`
  utilities resolve to the self-hosted fonts (they currently do not).
